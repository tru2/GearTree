GearTree Commands
=================

Basic Commands
--------------
//gt show | on
    Show the GearTree window.

//gt hide | off | close
    Hide the GearTree window.

//gt toggle
    Toggle GearTree visibility.

//gt reload | r
    Re-parse and rebuild the currently loaded GearSwap file.

//gt help | ?
    Show player command help.

//gt devhelp
    Show developer and diagnostic commands.


Views
-----
//gt mode raw
//gt raw
    Display sets closer to the actual GearSwap Lua structure.

//gt mode organized
//gt organized
//gt organised
    Display sets in organized gameplay categories.

//gt mode toggle
    Toggle between Raw and Organized views.

//gt expandall
    Expand all folders and categories.

//gt collapseall
    Collapse all folders and categories.


Navigation
----------
//gt find <text>
    Jump to a matching set, folder, or gear item.

//gt up
//gt down
    Move selection up or down.

//gt expand
    Expand the selected folder or category.

//gt back
    Collapse or move back from the selected entry.

//gt select
    Select the highlighted entry.

//gt equip
    Equip the highlighted gear set.

//gt last
    Jump back to the last saved set.


Saving & Editing
----------------
//gt save
    Save changed equipped gear back into the selected set.

//gt saveslot <slot>
    Save only the currently equipped item for one slot.

//gt undo
    Restore the most recent GearTree save backup.


Notes
-----
//gt note <text>
    Save a personal note on the selected set or folder.

//gt note
    Display the current note.

//gt note clear
    Remove the current note.


Folders & Layout
----------------
//gt make <folder> [root]
    Create a display folder.

//gt move <set> to <folder>
    Move a set into a display folder.

//gt move [set] up|down|top|bottom
    Reorder display items.

//gt move here
    Move the last saved set into the selected folder.

//gt rename <new>
//gt rename <folder> to <new>
    Rename a folder or display item.

//gt remove [folder]
    Remove a display folder.

//gt unmove [set]
    Return a moved set to its original location.

//gt layout reset
    Reset all display layout changes.


Interface Settings
------------------
//gt pos
    Show the current window position.

//gt pos <x> <y>
    Move the window.

//gt opacity
    Display the current opacity setting.

//gt opacity <35-100>
    Set window opacity. 100 is fully opaque.

//gt opacity reset
    Restore default opacity.

//gt scale
    Display the current UI scale.

//gt scale <0.75-2.0>
    Resize the whole GearTree window.

//gt scale reset
    Restore default UI scale.

//gt mouse on
//gt mouse off
    Enable or disable left-click activation.

//gt mouse status
    Display current mouse mode.

//gt shift on
//gt shift off
    Enable or disable Shift+Arrow navigation.
    Default: ON. When on, plain arrow keys pass through to FFXI and
    Shift+Arrow keys control GearTree navigation.
    Existing users may need to run //gt shift on to enable the new default.

//gt shift status
    Display current keyboard navigation mode.

//gt clicklock on
//gt clicklock off
    Enable or disable Click Lock.
    Default: ON. When on, mouse clicks over the GearTree window are consumed
    and do not pass through to FFXI. Clicks outside GearTree always pass
    through to the game normally.
    Existing users may need to run //gt clicklock on to enable the new default.

//gt clicklock toggle
    Flip Click Lock between on and off.

//gt clicklock status
    Display current Click Lock state.

//gt cursor on
//gt cursor off
    Show or hide the visual pointer inside GearTree.

//gt cursor status
    Display current pointer setting.


Keyboard Controls
-----------------
Up / Down
    Navigate the tree or scroll the active preview tab.

Left
    Collapse folders or move back.

Right
    Expand folders or move forward.

End
    Equip the selected set.

Esc
    Close GearTree.

Shift + Arrow Keys
    Used for GearTree navigation when //gt shift on is enabled.


Mouse Controls
--------------
Left Click
    Select, expand, or equip entries when mouse mode is on.

Right Click
    Open previews and details.

Mouse Wheel
    Scroll content.

Drag Header
    Move the window.


Developer / Diagnostic Commands
-------------------------------
Developer and diagnostic commands are hidden from normal help.
Use:

//gt devhelp
    Show debug, source, theme, calibration, and diagnostic commands.
