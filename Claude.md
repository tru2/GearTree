# GearTree Project Rules

Always start in planning mode.

Before editing:
1. Identify exact file(s) involved.
2. Explain the issue.
3. Propose the smallest possible fix.
4. Wait for approval.

Rules:
- No file edits without approval.
- No broad refactors.
- Preserve existing behavior.
- Do not rewrite unrelated systems.
- Prefer localized patches.
- Show diffs before major edits.
- Keep Windower compatibility.
- Avoid token-heavy exploration.
